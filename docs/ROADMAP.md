# KaiAI Future Ideas

These are extension points intentionally kept separate from the stable core:

1. Public web dashboard with secure per-guild configuration (no website accounts).
2. Redis-backed rate limits for multi-instance deployments.
3. PostgreSQL adapter for very large servers.
4. AI conversation summaries instead of raw long-term transcripts.
5. Role rewards at level milestones.
6. Scheduled events and recurring reminders.
7. Music adapter using a dedicated audio service.
8. Moderation case management with immutable case IDs.
9. Configurable reaction roles.
10. Server onboarding wizard.
11. Multi-language response profiles.
12. Per-channel AI policies and budgets.
13. Metrics export (Prometheus/OpenTelemetry).
14. Backup rotation and retention policy.
15. Plugin marketplace architecture with signed packages.
16. Public game arena with seasonal rankings and transparent virtual-currency rules.

The current release intentionally avoids adding these dependencies until they are needed.
